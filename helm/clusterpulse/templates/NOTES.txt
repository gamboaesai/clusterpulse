ClusterPulse has been deployed successfully.

1. Check the application status:

   kubectl get pods -n {{ .Release.Namespace }} -l app=clusterpulse

2. Access the ClusterPulse API:

   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "clusterpulse.fullname" . }} 8080:{{ .Values.service.port }}

3. Open the API documentation:

   http://localhost:8080/docs

4. Check application health:

   http://localhost:8080/health

5. Run the Helm connection test:

   helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
